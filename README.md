# 💰 Finance Tracker v1.0 by Арсений Гусев

Локальный трекер личных финансов на Python. Строгий тёмный дизайн с белым акцентом, мягкий градиентный фон (без анимаций и мерцания — всё содержимое отрисовывается сразу). Все данные хранятся только на вашем компьютере (SQLite в `%APPDATA%\FinanceTracker\fintracker.db`).

## Запуск

- **Windows:** откройте `FinanceTracker.exe`. Первый запуск может занять 10–20 секунд — это нормально для one-file сборки.
- **Из исходников:** `pip install customtkinter matplotlib pillow numpy`, затем `python fintracker.py`

При первом запуске программа предложит загрузить **демо-данные за 6 месяцев**. Удалить их: *Настройки → Очистить все данные*.

## Разделы

| Раздел | Что умеет |
|---|---|
| **Дашборд** | Приветствие, KPI-карточки (доходы, расходы, общий баланс) со сравнением с прошлым месяцем, график за 6 месяцев, структура расходов с суммой в центре, сводка месяца и таблица последних операций месяца |
| **Транзакции** | Поиск, фильтр «все/расходы/доходы», удаление **в один клик без подтверждения**; на узком окне таблица автоматически перестраивается в компактный вид |
| **Бюджеты** | Лимиты по категориям, прогресс-бары (зелёный → жёлтый → красный), прогноз на конец месяца; кнопка ✕ удаляет бюджет сразу, без вопросов |
| **Финансы** | Ваши счета (создание, переименование, удаление), кнопки **«Пополнить» / «Снять»** — проводят доход/расход прямо на выбранный счёт («откуда/куда»), переводы между счетами, лента последних операций с быстрым удалением |
| **Настройки** | Тема (тёмная/светлая/системная), масштаб интерфейса (90–125%), вкл/выкл градиентного фона, валюта (пресеты или свой символ), список горячих клавиш, управление категориями (добавление/удаление чипсами), экспорт CSV, демо-данные, очистка |

## Горячие клавиши

| Комбинация | Действие |
|---|---|
| `Ctrl+N` | Новая транзакция |
| `Ctrl+T` | Перевод между счетами |
| `Ctrl+1…5` | Переход к разделу по номеру |
| `Alt+← / →` | Предыдущий / следующий месяц |
| `Esc` | Закрыть диалог |

Все диалоги подтверждают действие по `Enter`.

## Адаптивность

Окно можно уменьшать до 880×600 — страницы прокручиваются, карточки перестраиваются в 1–2 колонки, список транзакций переходит в компактный режим. Ничего не съезжает и не обрезается.

## Файлы проекта

- `fintracker.py` — весь код приложения
- `make_icon.py`, `app.ico` — строгая монохромная иконка
- `verify_gui.py` — автотест интерфейса (27 проверок: страницы, графики, адаптивность, темы, хоткеи)
- `FinanceTracker.exe` — готовый исполняемый файл

## Проверки без GUI

```
python fintracker.py --selftest
```

23 проверки слоя данных: балансы, переводы, пополнение/снятие, бюджеты, удаление категорий, экспорт CSV, демо-данные, настройки.
